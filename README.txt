PAKET HALAMAN TUGAS SURAT RESMI

ISI FOLDER
- index.html              Halaman petunjuk tugas
- Surat Resmi.docx        Template surat resmi
- Data Surat Resmi.xlsx   Sumber data mail merge (10 penerima)

CARA MENJALANKAN
1. Ekstrak ZIP ini.
2. Pastikan ketiga file berada dalam folder yang sama.
3. Buka index.html di browser untuk melihat halaman tugas.
4. Tombol unduh pada halaman akan mengambil file DOCX dan XLSX dari folder yang sama.

CARA MEMPUBLIKASIKAN
Unggah ketiga file tersebut ke direktori/root hosting yang sama. Halaman dapat dipublikasikan melalui GitHub Pages atau hosting statis lain. Jangan hanya mengunggah index.html, karena tombol unduh membutuhkan dua file pendamping.
