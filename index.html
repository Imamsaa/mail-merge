Membuat Surat Resmi dengan Mail Merge

Gunakan Microsoft Word dan Microsoft Excel untuk membuat surat resmi secara otomatis berdasarkan data penerima.

Microsoft Word Microsoft Excel 10 data penerima

Mulai dari sini

Unduh file tugas

Unduh kedua file berikut. Simpan dalam satu folder agar mudah ditemukan saat mengerjakan Mail Merge.

DOCX Surat Resmi.docxTemplate surat resmi — Microsoft Word ↓ XLSX Data Surat Resmi.xlsxData penerima — Microsoft Excel ↓
✓
Target tugas: hasilkan surat untuk seluruh penerima pada file Excel. Data yang tersedia berjumlah 10 baris penerima. Jangan mengubah nama kolom pada baris pertama Excel.

Panduan pengerjaan

Langkah-langkah Mail Merge

Ikuti urutan berikut di Microsoft Word desktop. Nama menu dapat sedikit berbeda tergantung versi Word.

01

Siapkan kedua file

Unduh template Word dan data Excel. Simpan keduanya di satu folder. Buka Surat Resmi.docx menggunakan Microsoft Word.

02

Mulai Mail Merge

Pilih tab Mailings, lalu pilih Start Mail Merge dan tentukan jenis Letters.

Mailings → Start Mail Merge → Letters
03

Hubungkan data Excel

Pilih Select Recipients → Use an Existing List. Cari file Data Surat Resmi.xlsx, pilih sheet Sheet1, lalu pastikan baris pertama berisi nama kolom.

Mailings → Select Recipients
04

Masukkan Merge Field

Ganti setiap titik-titik pada template dengan field yang sesuai. Letakkan kursor di posisi yang benar, lalu pilih Insert Merge Field dan klik nama kolomnya.

Mailings → Insert Merge Field
05

Periksa hasil sementara

Klik Preview Results. Gunakan tombol navigasi untuk melihat data penerima berikutnya. Pastikan nama, kelas, nomor, dan isi surat berubah sesuai data.

Mailings → Preview Results
06

Buat seluruh surat

Pilih Finish & Merge → Edit Individual Documents → All. Word akan membuat dokumen baru berisi surat untuk semua penerima.

Finish & Merge → Edit Individual Documents
07

Simpan hasil akhir

Simpan dokumen gabungan dalam format Word. Setelah diperiksa, ekspor atau simpan juga sebagai PDF bila diperlukan.

File → Save As / Export → PDF
08

Periksa tata letak

Pastikan tidak ada field yang tertinggal, teks terpotong, atau tanda titik-titik dari template. Periksa setiap surat sebelum dikumpulkan.

Referensi field

Field yang harus dimasukkan

Gunakan nama field dari Excel berikut. Masukkan melalui menu Insert Merge Field, bukan mengetik tanda kurung siku secara manual.

Tips penempatan

Contoh: pada kalimat “Sehubungan dengan … latar belakang …” sisipkan field Latar_Belakang. Pada baris nama penerima, sisipkan field Nama.

Jangan ubah sumber data

Jangan mengganti atau menghapus judul kolom di Excel. Jika nama kolom berubah, Word bisa gagal menemukan field yang digunakan.
